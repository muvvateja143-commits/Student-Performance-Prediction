# 🎓 Student Performance Prediction

A Machine Learning project that predicts a student's overall academic performance based on their examination scores.

## 📌 Project Overview

This project uses Machine Learning to analyze student examination performance and predict an overall score.

The application provides a simple web interface where users can enter:

- Mathematics score
- Reading score
- Writing score

The trained Machine Learning model then predicts the student's overall performance.

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- Random Forest Regression
- Joblib
- Streamlit

## 📊 Dataset

The project uses the **Students Performance in Exams** dataset.

The dataset contains student examination scores including:

- Math Score
- Reading Score
- Writing Score

## 🤖 Machine Learning Model

A **Random Forest Regression** model is used to predict the student's overall score.

The model is trained using:

- Mathematics Score
- Reading Score
- Writing Score

### Model Performance

The trained model achieved a Mean Absolute Error (MAE) of approximately:

**0.46**
